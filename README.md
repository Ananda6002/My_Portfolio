# Ananda's Developer Portfolio

Create a modern, professional, recruiter-friendly personal portfolio website for me as a Computer Science & Engineering student and Full-Stack Developer.

1. Overall Goal

Build a polished portfolio that presents me as a serious software developer and showcases my full-stack development skills, projects, education, achievements, and contact information.

The website should look professional enough for:

Software developer job applications

Campus placements

Recruiters

Internship applications

LinkedIn/GitHub visitors

Do NOT make it look like a generic template. It should feel like a custom developer portfolio.

2. Design Direction

Use a modern developer-focused design with:

Dark theme as the primary theme

Clean, premium, minimal UI

Excellent typography

Subtle gradients

Glassmorphism only where it improves the design

Smooth animations

Professional hover effects

Good spacing and visual hierarchy

Responsive design for desktop, tablet, and mobile

Avoid excessive animations or flashy effects

Avoid unnecessary 3D elements

Keep the website fast and professional

Use a consistent design system throughout the website.

Add a light/dark theme toggle if it can be implemented cleanly.

Do NOT invent projects, certifications, internships, achievements, technologies, statistics, or experience.

Do NOT add fake GitHub stars, project users, downloads, or company experience.

Do NOT add information that I haven't provided.

If information is missing, either omit that section or use a clean placeholder that I can edit later.

All buttons and links must work.

External links should open safely in a new tab where appropriate.

Do not use lorem ipsum.

Do not use generic filler text.

Keep the writing concise and professional.

Prioritize recruiter readability.

Make the portfolio visually impressive without sacrificing usability.

Make the code clean, modular, and maintainable.

Use reusable components.

Make sure there are no console errors or broken links.

Before considering the project complete, test all navigation links, buttons, responsive layouts, and interactive elements.
